## 10. 重新生成与核对

刷新官方引用：

```powershell
git fetch upstream main
git rev-parse upstream/main
git merge-base upstream/main HEAD
```

检查已提交的个人差异：

```powershell
git diff --name-status --find-renames upstream/main...HEAD
git diff --stat upstream/main...HEAD
git log --oneline --reverse upstream/main..HEAD
```

检查尚未提交的现场：

```powershell
git diff --name-status HEAD
git ls-files --others --exclude-standard
```

最终提交和推送前还必须执行：

```powershell
git status --short --branch
git diff --check
git remote -v
```

核对规则：

1. 最终文件数和分类必须与实际 Git 差异一致；
2. `upstream/main` 变化后必须更新本节基准提交和文件差异；
3. `origin` 与 `upstream` 的角色不得互换；
4. `upstream` push 必须继续显示为 `DISABLED`；
5. 新增文件、资源文件和测试文件不得遗漏；
6. 工作区修改与已经提交并推送的内容必须分开陈述；
7. README 重命名、上游快照和个人首页必须作为独立文件核对；
8. 不得向文档写入账号、Token、授权码、PKCE 或未脱敏日志。
